# 🐾 PetSitter Landing Page

Uma Landing Page responsiva e moderna desenvolvida para o nicho de **PetSitter** (cuidados com animais de estimação). Este projeto foi criado com o objetivo prático de consolidar conhecimentos fundamentais em desenvolvimento front-end, aplicando conceitos estruturais de semântica, estilização moderna e interatividade fluida.

---

## 🚀 Sobre o Projeto

O projeto consiste numa página de captura e apresentação de serviços de PetSitter, desenhada para converter visitantes em clientes. O desenvolvimento foi inteiramente baseado na metodologia **Mobile First**, garantindo que a experiência do utilizador seja nativa e fluida em smartphones antes de se expandir de forma otimizada para tablets e desktops.

### ✨ Funcionalidades Principais

* **Abordagem Mobile First Real:** Todo o código CSS foi estruturado de forma progressiva, garantindo leveza e excelente performance em dispositivos móveis.
* **Menu Hambúrguer Dinâmico:** Implementação de um menu de navegação que se transforma dinamicamente: formato hambúrguer em ecrãs menores e menu expandido tradicional em ecrãs maiores.
* **Carrossel de Avaliações Interativo:** Uma seção dedicada à prova social, exibindo depoimentos de clientes através de um carrossel dinâmico e responsivo que melhora o engajamento e a conversão.
* **Navegação com Topo Fixo (Sticky Header):** A barra de menu permanece fixa no topo do ecrã durante a rolagem, permitindo o acesso rápido a qualquer secção do site a qualquer momento.
* **Rolagem Suave Otimizada (Smooth Scroll):** Configuração de rolagem suave com compensação exata de espaçamento (`scroll-padding-top` ou ajuste via JavaScript), evitando que a barra fixa "corte" ou oculte o início do conteúdo das secções navegadas.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias nativas (Vanilla Web Tech), focando na escrita de código limpo e sem dependência de frameworks externos:

* **HTML5:** Estruturação semântica da página (`<header>`, `<section>`, `<main>`, `<footer>`), melhorando a acessibilidade e o SEO.
* **CSS3:** Estilização baseada em propriedades modernas como Flexbox/Grid, variáveis CSS, transições suaves e Media Queries para responsividade.
* **JavaScript (ES6):** Manipulação do DOM para controlo de abertura/fecho do menu, lógica do carrossel de avaliações e controlo dos eventos de navegação.

---

## 📐 Conceitos Aplicados

Durante o desenvolvimento deste projeto, foram colocados em prática os seguintes padrões do mercado:

1. **Responsividade Baseada em Breakpoints:** Adaptação fluida do layout para diferentes resoluções.
2. **UX/UI (Experiência do Utilizador):** Foco no contraste de cores, legibilidade, prova social integrada e acessibilidade na navegação.
3. **Clean Code:** Organização lógica do ficheiro de estilos e nomenclatura clara para classes e funções.
